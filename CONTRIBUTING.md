# Contributing to OSINT Framework

First off, thank you for considering contributing!

## How Can I Contribute?

### Reporting Bugs
- Ensure the bug was not already reported by searching on GitHub under [Issues](https://github.com/user/osint-framework/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/user/osint-framework/issues/new).

### Suggesting Enhancements
- Open a new issue and describe the enhancement you would like to see.

### Pull Requests
- Fork the repo and create your branch from `main`.
- Make sure your code lints (`make lint`).
- Test your changes (`make test`).
- Issue that pull request!
